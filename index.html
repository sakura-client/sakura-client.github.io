Install

Ready in a minute.

Sakura runs on Fabric. If you already play modded, you only need the last step.

Install Java 21

Sakura needs Java 21 or newer. Current Minecraft launchers already include it.

Install Fabric

Get Fabric Loader 0.19+ for Minecraft 1.21.11.

Add Fabric API

Drop Fabric API into your mods folder. Sakura needs it to load.

Add Sakura

Put SakuraClient-v2.jar in mods, start the game, and enjoy.
